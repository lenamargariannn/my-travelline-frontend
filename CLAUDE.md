# MyTravelLine Frontend Project

This is the frontend codebase for MyTravelLine, a travel agency website.

## Brand Logo

Use the MyTravelLine logo located at:

```text
public/logo.png
```

## Brand colors

- Main text: #0C0809
- Brand blue: #2E7D9C
- Brand red: #CB2912
- Background: #E8F9FF

## Design direction

The website should feel modern, clean, travel-focused, trustworthy, and responsive.
Use rounded cards, soft spacing, clear CTAs, and a professional layout inspired by traveldoor.ge but not copied exactly.

## Main pages/sections

The homepage should include:

- Header with logo and navigation
- Hero section with search form
- Popular destinations
- Featured tours
- Travel services
- Why choose us
- Testimonials
- CTA banner
- Footer

## Coding preferences

- Keep components reusable
- Use clean naming
- Avoid unnecessary dependencies
- Make the layout responsive
- Use semantic HTML where possible
- Do not break existing routes or components
